# XAMLE AGRI — prototype (version statique)

Prototype de démonstration de l'application XAMLE AGRI (assistance, formalisation, B2B pour les acteurs agricoles au Sénégal).

**En ligne :** https://xamle.maisquand.com

- Pages HTML/CSS/JS sans serveur : hébergé sur GitHub Pages.
- Les données de démo sont dans `assets/data.js` (fictives ou à confirmer).
- L'avancement de la démo est enregistré dans le navigateur du visiteur (localStorage).
  « Réinitialiser » remet la démo à zéro, « Déconnexion » efface tout.
- Connexion : n'importe quel numéro sénégalais valide ; le code s'affiche à l'écran (aucun SMS envoyé).

Simulés : SMS, paiements Wave / Orange Money, PDF, reconnaissance vocale.
